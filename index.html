// Deployment Guide

Free Portfolio Hosting on GitHub Pages

Since this portfolio is built as a single, lightweight static HTML file, you can host it 100% free with automatic SSL and custom domains on GitHub Pages.

Quick CLI Deployment Commands

# 1. Initialize git in your portfolio folder

git init

# 2. Add your index.html file

git add index.html

git commit -m "feat: initial release of professional portfolio"

# 3. Connect to your GitHub repository (replace with your repo URL)

git branch -M main

git remote add origin https://github.com/surajnarayanan/surajnarayanan.github.io.git

# 4. Push to GitHub

git push -u origin main

STEP 01
Create a public repository named username.github.io on GitHub.
STEP 02
Save this code locally as index.html and push via Git.
STEP 03
Go to repo Settings > Pages, ensure branch is main / root.
